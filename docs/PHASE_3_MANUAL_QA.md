# Phase 3 manual QA

1. Run `npm run dev`.
2. Log in.
3. Open Dashboard and verify real ingestion metrics appear.
4. Open Sources and verify enabled and failed sources are understandable.
5. Open Jobs and confirm real roles and official application links appear.
6. Open one job and confirm its description renders as safe text.
7. Confirm qualification remains Pending.
8. Confirm no contacts, outreach, or emails were created.
9. Confirm DRY RUN and automatic outreach disabled remain visible.
10. Open a few official application links manually and verify they resolve to the corresponding role.

Do not verify every ingested role manually. Do not enter applicant information or submit an application during this QA.
